# Thư mục Assets cho Rừng Cổ Tích 3D

## Các file cần có:

### Bắt buộc:
- `player.glb` - Model nhân vật hiệp sĩ (có animations Idle, Run)
- `wolf.glb` - Model con sói (có animations Idle, Run)

## Cách lấy models:

### Cách 1: Mixamo (Miễn phí)
1. Vào https://www.mixamo.com/
2. Đăng ký/Đăng nhập
3. Upload character hoặc chọn từ thư viện
4. Tải về định dạng .glb

### Cách 2: Quixel / Unreal Engine Marketplace
- Nhiều characters miễn phí

### Cách 3: Tự tạo bằng Blender
1. Tải Blender miễn phí
2. Import hoặc tạo model
3. Thêm animations (Idle, Run)
4. Export as .glb

## Yêu cầu cho Animation:
- Animation clip phải có tên: `Idle` và `Run`
- Loop mode: LoopRepeat
